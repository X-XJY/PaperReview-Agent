# 评测与验收

## 已有自动化检查

运行 `python -m pytest -q`。测试全部使用本地教学样例、生成的空白 PDF 或 mock 外部服务，不产生真实 API 费用。

- 样例数据通过 Paper / Synthesis 契约。
- 会话隔离、跨站写请求防护、PDF 文件访问隔离。
- 无效 PDF / 超批量拒绝、同批去重与任务复用。
- 不存在的证据拒绝、人工修订版本冲突、报告过期标记。
- 解析内容页码转换与分块不丢内容。
- 虚构图谱端点和仅单篇支持的共性缺陷被移除。
- 模型缓存命中不再请求供应商，修改模型会失效。
- 5 篇和 8 篇完整 mock 流程、人工修改、重算后状态更新、不重复 PDF 解析。

这些证明程序契约，不证明论文抽取准确率。

## 真实论文评测（待接入密钥后执行）

准备 12—16 篇有权处理的 RAG 论文，至少覆盖双栏、表格、明确局限和缺少局限四种情况。区分开发集和未用于调 Prompt 的测试集；每批最多 8 篇。两名团队成员独立标注，第三人裁决分歧。

每条金标记录 paper_id、字段、正确陈述、原文证据、页码、允许的标签。不得把教学样例混入准确率报告。

报告：

| 指标 | 计算方式 |
|---|---|
| 局限精确率 | 原文确实支持的抽取局限 / 所有抽取局限 |
| 局限召回率 | 命中的人工标注局限 / 全部人工标注局限 |
| 标签准确度 | 与裁决标签比较，另外报告未归类率 |
| 引用有效率 | 可定位证据引用 / 所有引用 |
| 推断过度率 | 人工判为超出证据的结论 / 所有结论 |
| 演进边精确率 | 原文支持且关系解释正确的边 / 输出边 |
| 成本 | 每批实际输入/输出 Token × 当期供应商费率 |
| 耗时 | 冷缓存和热缓存分别报告 |

消融：相同模型和论文，对比一次性总结、结构化抽取、结构化抽取加自检。保持证据语料和输出目标一致；人工评分，不仅由同一模型自评。所有数字须实测，README 不预填 90% 等效果结论。
