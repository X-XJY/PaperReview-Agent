# AI 论文助教

在任务中点击“论文助教”，或在论文/结论/原文证据旁点击“问助教”。新对话可选择 1—8 篇已分析论文；对话开始后范围固定，切换范围需要新建对话。原始论文不再次上传到 MinerU。

四种活动：问论文、讲明白、比较论文、检查理解。直接讲解默认回答问题；启发引导按上下文给提示，用户可以要求完整讲解。直观/技术深度可随每轮调整。“仅依据论文”关闭背景讲解。理解题的下一轮可直接提交自己的答案。

每个回答块标注论文事实、背景讲解或研究假设，并展示证据支持状态。服务器回填引用片段与 PDF 页码；未通过核验的断言隐藏，部分支持和待核验内容保留告警。全文缺失类表述额外降级提醒，不能由部分检索证明。背景知识不标记为已被论文支持。公式使用安全的 Markdown/KaTeX 渲染；原始 HTML、远程图片和模型生成的链接不执行。

## 服务与配置

- 原有 API 和论文 worker 保留，增加 `python -m backend.tutor_worker`，且仅运行一个助教 worker。
- Ubuntu 使用 `deploy/paperreview-tutor.service`；Docker Compose 已包含 tutor 服务。
- 每会话无每日轮次限制；`TUTOR_GLOBAL_DAILY_TURNS=200`：全站轮次；`TUTOR_DAILY_TOKENS=1000000`：全站 token 预算。
- 每轮最多 5 次模型调用，包括检索词改写、生成、核验和所有重试。普通中文请求通常 3 次。每次调用前预留输入字节数与最大输出预算，供应商返回用量后核算；失败且无用量时保守保留预留额度。
- 对话请求使用独立队列和计量，不消耗论文任务的调用次数。默认全局助教并发为 1，每会话最多两个排队/运行请求。

## 检索与修订

原文与方法卡片通过英文词项、中文双字片段、术语映射和 BM25 排序召回。中文或多轮问题先生成中英检索词；卡片仅供导航，只有原文可以作为证据。每篇论文独立配额，最多 16 个片段；比较八篇时每篇最多两块，复杂对比建议按具体维度分轮。

历史只保留有界文本上下文，不作为证据，也不把旧答案中的引用副本再次塞给模型。索引按每次请求临时构建，不常驻全部用户语料。

回答缓存绑定会话、任务、范围、原文/抽取修订、问题、教学模式、有效历史和模型/Prompt 版本。请求 ID 支持网络重试去重。人工修正后旧回答显示过期；新请求不使用过期历史。生成期间修订也会标记结果过期，不自动覆盖用户修改。

默认保留 7 天；会话过期清理同时删除聊天数据。只有当前会话拥有的任务与证据可访问；服务端不信任浏览器传来的论文或证据 ID。

## 测试

`python -m pytest -q` 包含助教权限、引用、版本、上下文、预算、幂等与缓存测试；`tests/tutor_eval_cases.json` 提供 30 道 Transformer/BERT 检索与教学检查题。题目的 terms 只是检索诊断关键词，不应当被当成人工精确证据标注或事实正确率。

同一模型生成与核验不能完全消除幻觉。请核对原 PDF；现阶段不宣称具有长期学习画像、独立模型裁判或已经通过大规模教学效果实验。

## 本次验证记录（2026-09-11）

- 自动化：29 项后端测试、5 项 Windows 打包测试通过；TypeScript/Vite 生产构建通过。
- 使用用户提供的 Transformer v7、BERT v2 已解析原文，未重新调用 MinerU。真实 DeepSeek 测试完成公式解释、双论文对比、首次出题、错误回答反馈、要求完整答案和虚构基准问题共六个场景。
- 首次出题不再提前输出答案；错误的“全部替换为 MASK”能由原文纠正；要求完整答案后不再反问；虚构基准未生成虚假准确率。
- 检索诊断的前 20 道题均在候选片段中命中至少一个预设关键词。这只是关键词覆盖，不是人工标注的召回率或教学准确率。
- 实测仍发现模型可能把“片段未出现”概括成“论文未报告”。对此增加服务器端保守告警；这不是完整的语义校验，不能据此宣称零幻觉。八篇复杂综合问题尚未做真实质量评测。

## 对话删除与 PDF 导出

历史对话下拉框选中会话后可删除整个对话；分析历史中的删除会同时清除关联对话及修订记录。处理中的任务须等待结束再删除。原 PDF 与共享解析缓存仍按原有保留周期清理。

下载按钮导出完整已完成问答的 PDF，仅包含用户提问和助教回答（含助教追问），不包含原文片段、核验原因、调用统计或推荐问题；未完成轮次不导出。中文字体嵌入 PDF，Ubuntu 安装 `fonts-wqy-zenhei`，Windows 默认使用系统黑体，也可设置 `PDF_CJK_FONT` 为支持嵌入的中文 TrueType 字体路径。公式保留回答中的文本表达。
